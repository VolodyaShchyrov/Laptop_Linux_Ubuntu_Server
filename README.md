# Laptop_Linux_Ubuntu_Server

Home server on an old Toshiba laptop running Ubuntu Server.
Stack: Linux, Docker / Docker Compose, UFW / iptables, Tailscale, BIND9, SSH, automation scripts.

## Structure

| Path | Purpose |
|------|---------|
| `state/server-state.md` | Single source of truth for the current server state. Updated after every stage. |
| `docs/` | Stage write-ups (`NN-stage-name.md`): what was done, commands/configs, errors and fixes, short theory. |
| `logs/` | Raw working notes and error output per stage. |
